Privacy Policy

Westfield E2E - last updated 21 September 2026

1. Purpose

Westfield E2E is an internal quality-assurance tool. It supports the automated end-to-end tests of the password-reset journey of the Westfield website. It has no end users and is not offered to the public.

2. Data accessed

  • The tool accesses only the dedicated test mailbox testautowestfield@gmail.com, which is owned and operated by the QA team.
  • It uses the Google Gmail API with the read-only scope https://www.googleapis.com/auth/gmail.readonly.
  • It searches recent password-reset emails sent to test aliases of that mailbox and reads their content to extract the reset link.
  • The mailbox only receives emails for disposable test accounts. It contains no personal data of real customers.

3. How the data is used

The extracted reset link is used once, during the test run, to complete the password-reset journey. Email content is not used for any other purpose.

4. Storage and retention

  • Email content is processed in memory during the test run and is not stored in a database.
  • Test reports produced by the CI pipeline may contain execution logs; they are kept for a limited period (14 days) and are accessible only to the QA team.

5. Sharing

Data obtained through the Gmail API is not sold, shared with third parties, used for advertising, or used to train artificial-intelligence models.

6. Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Revoking access

Access can be revoked at any time from the Google account security settings: myaccount.google.com/permissions.
