Westfield E2E

Internal QA tool for the automated end-to-end test suite of the Westfield website.

This application is used only by the QA test-automation team. It is not a public service and has no end users.

What it does

During automated tests of the password-reset journey, the test suite requests a password reset for a disposable test account, then uses the Gmail API with the read-only scope to find the reset email in a dedicated test mailbox and extract the reset link.

Scope of access

  • Only the dedicated test mailbox testautowestfield@gmail.com is accessed.
  • Access is read-only (gmail.readonly). The tool never sends, modifies or deletes emails.
  • No personal data of real customers is processed.
